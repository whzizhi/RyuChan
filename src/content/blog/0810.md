## 安装

- 有代理：去 OpenAI 官网下载 ChatGPT 桌面应用（原 Codex 已并入其中，应用内提供 Chat、Work、Codex 三个入口）。
- 无代理：在微软应用商店搜索 ChatGPT 下载。

## 配置工具 CC Switch

用于在多种接入方式间切换配置，支持 Claude Code、Codex 等。有 GitHub 访问条件的直接下载最新版（教程演示版本为 3.16.5），双击安装即可。

## 接入方式（三选一）

1. **国内模型（如 DeepSeek）**：适合无网络基础的用户。给 DeepSeek 充值并创建 API Key → 在 CC Switch 的 Codex 菜单中新建 DeepSeek 渠道、填入 Key → 启用渠道并开启路由 → 重启 Codex。注意：DeepSeek 暂不支持多模态，无法在 Codex 里发图片。
2. **中转站 API**：适合没有网络条件、没有 GPT Plus 但想用 GPT 模型、想按量付费的用户。在 CC Switch 中选择 apinebula 等中转渠道，分组选 codex，重启 Codex 即可。
3. **ChatGPT 账号**：最推荐，但需自行解决网络、账号、支付问题。准备好 Plus 账号后，直接在 Codex 里登录即可。

**关于接码**：仅免费账号或 0 元试用账号登录时会弹手机号验证；给 OpenAI 付费（如代充 Plus）后，绝大多数情况不会再要求验证。建议先付费再考虑接码。

## 常见问题

- **设置中文无效**：Codex 需联网下载中文语言包，没有代理时设置不生效。
- **账号接入必须配置代理**：否则发消息会一直 Reconnection。在 `.codex` 目录创建 `.env` 文件，填入：

  ```
  HTTP_PROXY=http://127.0.0.1:7890
  HTTPS_PROXY=http://127.0.0.1:7890
  ALL_PROXY=http://127.0.0.1:7890
  NO_PROXY=localhost,127.0.0.1
  ```

- **插件无法使用**：API 接入用不了插件，可用 Codex++ 解锁；Computer Use 插件账号接入也可能不可用。

## Chat / Work / Codex 的区别

- **Chat**：讨论、解释、构思、快速问答（"告诉我怎么做"）。
- **Work**：研究资料，制作文档、表格、报告、演示稿（"帮我产出一个东西"）。
- **Codex**：面对真实文件、代码仓库、终端和软件完成任务（"进入我的环境，把它真正做完并验证"）。

额度方面：Work 与 Codex 共享 Agentic usage（智能体用量）额度池；Chat 主要消耗普通消息额度；图片生成、文件上传、语音等各有独立限制。

## 文件权限与安全

Codex 能做什么取决于：打开的项目目录、沙箱和审批设置、是否允许联网、插件授权、系统安全策略。完全访问权限下沙箱不再限制，审批也通常变为永不询问——授予权限时需谨慎。

## 实用功能

- **Git 操作**：修改前提交一次，完成后验证再提交一次，方便对比和回滚。
- **Plan 计划模式**：先检查项目现状、分析需求、评估风险、给出方案，再动手实施。适合重构老项目、换数据库、设计新功能、排查疑难 bug 等高风险任务。
- **定时任务**：让 Codex 按指定时间自动执行，如每日总结、定期检查 TODO、监控部署和 PR 等。分独立定时任务（适合日报、巡检）和当前任务内定时执行（适合长期跟踪）。
- **浏览器操作**：适合网页任务——搜索资料、填写网页、测试自己开发的网站、截图验证。最有价值的用法是"修改代码 → 启动网站 → 浏览器验证 → 发现问题 → 修复 → 再验证"。
- **Computer Use**：通过观察屏幕操作桌面应用（文件管理器、Excel/Word、无 API 的旧软件等），范围比浏览器更大。
