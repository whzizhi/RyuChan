给 macOS / Windows 的 Codex 桌面端换上灰泽满的皮肤。
以她的代表色 #D3D3D3 浅灰为底，绿冻色 #5C968E 作交互强调，配官方立绘与语录。
一个不碰官方二进制的外观方案：

原生控件：侧栏、建议卡、项目选择、输入框仍是可点击的原生 UI，不是整窗假截图
本地注入：通过本机回环 CDP（127.0.0.1）注入 CSS 与装饰 DOM
不动核心：不改 app.asar / WindowsApps / 代码签名，不碰 API Key 与 Base URL
深浅自适应：皮肤跟随 Codex 外观设置 / 系统主题自动切换浅色与深色两套色板
可一键还原：安装前自动备份配置，随时恢复官方外观
支持平台
平台	目录	安装入口	状态 / 日志目录
macOS	macos/	install.sh 或双击 .command	~/Library/Application Support/CodexDreamSkinStudio
Windows	windows/	install-dream-skin.ps1 / 一键 .bat	%LOCALAPPDATA%\CodexDreamSkin
两套平台共用同一套 Hazel 皮肤内容（theme.json 文案配色、主图、贴纸、CSS、注入逻辑），只是安装与进程管理脚本不同。
